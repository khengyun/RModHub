RModHub

RNA modification site prediction web server.

Paste an RNA (or DNA) sequence and RModHub scores every position for 12 modification types (Am, Cm, Gm, Um, m1A, m5C, m5U, m6A, m6Am, m7G, Ψ, A-to-I) with the MultiRM deep-learning model, returning the sites whose empirical p-value passes your threshold. The sequence branch is live; a nanopore signal branch (DirectRM) is planned.

Try the API

Interactive documentation: /docs

  • POST /api/predict/sequence — body {"sequence": "...", "alpha": 0.05}; add ?format=csv to download the result table.
  • GET /api/samples/sequence — a ready-to-submit example sequence.

Also: GET /health for server and model status.
