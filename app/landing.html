RModHub

RNA modification site prediction web server. Two ways in, one result table.

Sequence. Paste an RNA (or DNA) sequence and RModHub scores every position for 12 modification types (Am, Cm, Gm, Um, m1A, m5C, m5U, m6A, m6Am, m7G, Ψ, A-to-I) with the MultiRM deep-learning model, returning the sites whose empirical p-value passes your threshold.

Nanopore signal. Upload direct-RNA reads (a pod5 file plus the BAM produced by dorado --emit-moves, the reference FASTA and a regions CSV) and RModHub runs DirectRM per read and per site for ac4C, m1A, m5C, m6A, m7G and Ψ. Jobs run in the background; the job id is the only key to the result. A synthetic sample data set is built in.

Try the API

Interactive documentation: /docs

  • POST /api/predict/sequence — body {"sequence": "...", "alpha": 0.05}; add ?format=csv to download the result table.
  • GET /api/samples/sequence — a ready-to-submit example sequence.
  • POST /api/jobs/signal — multipart pod5, bam, reference, regions (+ kit) → 202 with a job id; or POST /api/jobs/signal/init for resumable (tus) uploads.
  • GET /api/jobs/{job_id} — status and progress; GET /api/jobs/{job_id}/results and /download.csv once done.
  • POST /api/jobs/signal/sample and GET /api/samples/signal — the synthetic nanopore sample.
  • GET /api/capabilities — which branches this server enables, its upload limits and the retention periods below.

Also: GET /health for server and model status.

No login required; no cookies are set.

Your data. Pasted sequences are processed in memory and are never written to disk. Nanopore uploads are stored on this server only for as long as processing needs them: the pod5 and BAM files are deleted as soon as feature extraction has finished (and in any case within {{inputs_max_age_h}} hours of upload); job results are kept for {{results_retention_days}} days after completion and then deleted. Unfinished uploads expire after {{upload_ttl_h}} hours. Client addresses are stored only as a keyed hash used for fair-use limits. There are no accounts: anyone with a job id can view that job's results.
